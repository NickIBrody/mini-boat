# Mini Boat

A small fuel-powered boat for Factorio 2.0. It can only be placed on and driven over water.

- Burns chemical fuel (coal, wood, solid fuel) and nuclear fuel
- 64 rotation directions, shadow, smoke from the smokestack
- Unlocked by the "Mini Boat" technology (requires Automobilism)
- Recipe: 12 engine units, 20 steel plates, 10 iron gear wheels, 40 iron plates

## Install

Download `mini-boat_0.1.2.zip` from the Releases page and put it, without unpacking, into the Factorio `mods` folder (`%appdata%\Factorio\mods` on Windows).

## По-русски

Небольшая лодка на топливе для Factorio 2.0. Ставится и плавает только по воде. Открывается технологией «Мини-лодка» после «Автомобилизма». Установка: положи zip из Releases в папку `mods`, не распаковывая.
